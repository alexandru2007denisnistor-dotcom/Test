# SoundTune EQ

Android-Equalizer (Android 9+) für Spotify, abgestimmt auf **Soundcore Space One** und **EarFun Air Pro 4**.

- 31-Band-Terz-EQ (DynamicsProcessing) mit 10 Reglern, weich interpoliert
- Kopfhörer-Korrektur + Sound-Profil (u. a. „Lana Del Rey · Warm & Cinematic“, Studio Neutral, Studio + Bass, Deep Bass, Vocal Klarheit)
- Auto-Preamp + Limiter gegen Übersteuern bei Bass-Boost
- Erkennt Spotify-Audio-Sessions automatisch, läuft im Hintergrund

**APK:** [`apk/SoundTuneEQ.apk`](apk/SoundTuneEQ.apk)

Bauen: `./gradlew assembleRelease` (benötigt Android SDK 35).
